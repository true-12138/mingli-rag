## 三、RAG 使用建议

1. **切分**：古籍按卷／篇切；`03-terminology/**.jsonl` 每条术语天然就是一个 chunk，可直接入库。
2. **metadata**：`术数-manifest.json` 与各 JSONL 的 `category` / `group` / `source` 字段建议保留为元数据，便于过滤检索。
3. **引用注意**：`02-oss-code/` 与 `03-terminology/` 中来自程序常量的条目（iztro、lunar、bazi-terms）是**现代实现的归纳**，回答时不应标注为古籍出处；只有 `01-classics/术数/` 的内容才是古籍原文。
4. **繁简**：殆知阁文本繁简混排，建议入库前统一转换。
5. **重跑**：`_scripts/` 下脚本可用 Node 24 / Python 3.11(`-S`) 重跑，重建全部派生文本。
