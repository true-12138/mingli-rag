中文命理 RAG
免责声明：本项目仅作为大模型检索增强生成（RAG）技术、古籍文本处理方向的学习研究项目。项目内古籍文本仅为文史资料，不提供任何命理预测，不构成人生决策建议，请勿将模型输出结果用于现实判断。
项目简介

市面上命理相关大模型回答大多泛泛而谈，缺少古籍原文溯源。本项目基于术数古籍知识库搭建RAG系统，检索优先匹配原始古籍文本，生成回答附带原文出处，实现答案可溯源。
语料采用分层管理：原始压缩包完整存档，人工完成门类分类后再开展数据处理，对每一类古籍单独评估文本质量，后续检索可携带门类元数据做过滤，减少跨类别干扰。

技术栈

Python | Pathlib | Dataclass | CSV | Pandas | Matplotlib
后续：文本清洗、古籍文本分块、Embedding、Milvus向量库
